# Security

TabSnap handles browser URLs. Treat that data as sensitive.

## Reporting

Do not open a public issue for a vulnerability.

Use GitHub's private vulnerability reporting if it is enabled for this repository. If it is not available, contact the repository owner through their GitHub profile before publishing details.

## Scope

Useful reports include:

- snapshot decryption without the password
- snapshot tampering accepted as valid
- unexpected network transmission
- privilege escalation
- arbitrary code execution
- unsafe handling of imported `.tabsnap` files

## Current status

TabSnap is pre-release software. No stable version exists yet.
