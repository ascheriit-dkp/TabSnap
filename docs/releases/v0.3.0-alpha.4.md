# TabSnap v0.3.0-alpha.4

Store-readiness alpha.

## Added

- extension icons at 16, 32, 48 and 128 pixels
- public privacy policy
- canonical Chrome / Edge / Firefox store listing copy
- reviewer notes and permission justifications
- store submission checklist and AMO source-build instructions
- automated store-readiness audit in `pnpm check`

## Firefox

Firefox now requires Desktop 140+.

Extension-only mode still declares no required data collection. Optional companion mode declares `browsingActivity` as optional data transmission because encrypted snapshots contain URLs and are sent to the local companion.

The permission is requested only when the user explicitly presses Connect. Declining it leaves companion mode disabled and does not affect capture, encrypted export/import or restore.

## Privacy

TabSnap still has no account, backend, analytics or telemetry. The optional companion receives encrypted snapshot bytes over authenticated IPv4 loopback. The snapshot password never leaves the extension.
