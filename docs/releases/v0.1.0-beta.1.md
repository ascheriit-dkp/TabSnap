# TabSnap v0.1.0-beta.1

This beta completes the Level 1 Chrome milestone.

It keeps the local-only capture, encryption and restore model from the alpha while removing the alpha's most important usability risk: long operations no longer run inside an ephemeral browser popup.

## Beta changes

- the toolbar action opens TabSnap as a persistent extension tab
- clicking the toolbar action again focuses the existing TabSnap tab instead of opening a duplicate
- capture, Argon2id encryption, decryption and restore can continue without depending on popup focus
- the workspace layout is adapted for a normal browser tab
- the built-artifact audit enforces the persistent launcher and still rejects remote resources and JavaScript network primitives
- the Chromium integration test now covers encrypted string export, wrong-password rejection, successful import and restore in one real-browser flow

## Privacy boundary

TabSnap still has no backend, account, telemetry or analytics. The extension requests only `tabs` and `tabGroups`, has no host permissions, injects no page-content scripts, and the launcher is packaged locally.

## Install

Download `tabsnap-chrome-v0.1.0-beta.1.zip` and optionally verify it against `tabsnap-chrome-v0.1.0-beta.1.zip.sha256`.

Extract the ZIP, open `chrome://extensions`, enable Developer mode, select **Load unpacked**, and choose the extracted directory containing `manifest.json`.

## Current scope

This beta targets Chrome. Edge, Firefox and the portable Windows companion remain later roadmap levels.
