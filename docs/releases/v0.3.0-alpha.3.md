# TabSnap v0.3.0-alpha.3

Cross-browser compatibility alpha.

## Added

- explicit restore-target detection for Chrome, Edge and Firefox
- compatibility assessment before restore
- known non-portable tabs reported in the import preview
- Chrome ↔ Edge compatibility coverage
- Chromium ↔ Firefox best-effort compatibility coverage
- documented feature-loss rules and cross-browser restore semantics

## Behavior

Same-browser restore remains the fidelity baseline.

Cross-browser restore is best-effort and non-destructive. TabSnap keeps the original snapshot unchanged, does not silently rewrite browser-specific URLs, and reports tabs the target browser is expected to reject.

The `.tabsnap` format, encryption, compression and companion protocol are unchanged.
