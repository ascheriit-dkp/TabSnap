# TabSnap v0.4.0-alpha.1

Level 4 whole-machine prerelease.

## Added

- explicit ephemeral companion registration for Chrome, Edge and Firefox;
- coordinated whole-machine capture across paired browser pages;
- versioned `.tabsnap-machine` containers holding bounded routing metadata plus opaque encrypted browser payloads;
- coordinated whole-machine restore with same-instance, same-browser and cross-browser fallback;
- partial capture/restore status with bounded failure reasons and retry;
- native Windows whole-machine UI showing connected browsers, capabilities and per-browser progress;
- machine-snapshot library beside the existing single-browser snapshot library;
- automatic machine-snapshot persistence after successful coordinated capture.

## Security and privacy

Browser workspace plaintext and snapshot passwords stay inside the browser extensions.

The Windows companion receives encrypted browser payloads and bounded coordination metadata only. It does not decrypt tabs, URLs, titles or groups.

The local bridge:

- binds only to `127.0.0.1`;
- uses a fresh 256-bit process-scoped pairing token;
- requires explicit browser pairing;
- validates extension origins for browser coordination;
- has bounded headers, bodies, registries, jobs and encrypted payload sizes;
- uses leases/timeouts for interrupted work;
- rejects duplicate terminal submissions and does not replay completed restores.

M34 adds hostile container/protocol tests plus multi-job isolation regression tests.

## Browser behavior

Chrome, Microsoft Edge and Firefox use the same encrypted browser snapshot format.

Same-browser restore is preferred. Cross-browser restore remains best effort and reports/skips browser-specific or privileged pages according to the existing adapter policies.

## 1.0 status

This is a prerelease, not `1.0.0`.

The automated Level 4 gates pass before publication, but stable 1.0 still requires the manual multi-browser, packaged-companion, removable-storage and real store/signing matrix documented in `docs/security/level4-readiness.md`.
