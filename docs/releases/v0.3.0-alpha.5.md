# TabSnap v0.3.0-alpha.5

Firefox companion interoperability fix.

## Fixed

- the Windows companion now accepts strict Firefox `moz-extension://<uuid>` origins in addition to Chromium `chrome-extension://...` origins
- Firefox can complete authenticated localhost companion requests instead of being rejected by the companion CORS origin check
- non-extension web origins remain rejected
- Bearer session authentication and IPv4-loopback-only transport are unchanged

## Validation

The fix is covered by a Firefox extension-origin preflight test and the full CI suite: static checks, Windows companion tests/build/smoke packaging, Chrome/Edge browser integration, Edge packaging and Firefox build/audit/lint/package.

## Privacy

TabSnap still has no account, backend, analytics or telemetry. The optional companion receives encrypted snapshot bytes over authenticated IPv4 loopback. The snapshot password never leaves the extension.
