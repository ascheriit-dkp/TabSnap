# TabSnap v0.1.0-alpha.1

This is the first public alpha of the Level 1 Chrome extension.

It is intended for manual testing before the beta milestone. Keep important browser sessions backed up and review the restore preview before creating new windows.

## What works

- capture normal Chrome windows and ordered tabs
- preserve pinning, active tabs, tab groups, group metadata, window geometry and state when Chrome exposes them
- encrypt snapshots locally with Argon2id + AES-256-GCM
- move snapshots as a copyable `tabsnap:v1:` string or encrypted `.tabsnap` file
- decrypt and preview locally
- restore non-destructively into new windows
- skip unsupported browser/extension URLs and report warnings instead of aborting the entire restore

## Privacy boundary

TabSnap has no backend, account, telemetry or analytics. The Chrome extension requests only `tabs` and `tabGroups`, has no host permissions and does not inject page-content scripts.

## Install

Download `tabsnap-chrome-v0.1.0-alpha.1.zip` and optionally verify it against `tabsnap-chrome-v0.1.0-alpha.1.zip.sha256`.

Extract the ZIP, open `chrome://extensions`, enable Developer mode, select **Load unpacked**, and choose the extracted directory containing `manifest.json`.

## Known limitation

Long operations currently run in the extension popup. Keep it open until capture, encryption, decryption or restore completes.
