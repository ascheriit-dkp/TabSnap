# TabSnap v0.2.0-alpha.1

Level 2 alpha.

## Added

- portable Windows companion executable
- portable, local and custom snapshot storage
- opaque encrypted `.tabsnap` library with atomic writes and collision-safe names
- authenticated `127.0.0.1` companion protocol with process-scoped pairing tokens
- opt-in Chrome bridge using optional loopback permission
- native Win32 companion UI
- companion library import/export and storage controls
- pairing-code display/copy from the native UI
- Windows executable smoke tests
- portable Windows ZIP + SHA-256 release asset

## Privacy boundary

The companion never receives the snapshot password and never decrypts browser state. Snapshot encryption/decryption remains inside the Chrome extension.

The local listener binds only to `127.0.0.1`. Its 256-bit session token is generated per process and is not written to disk.

The Chrome localhost permission remains optional and is requested only after an explicit Connect action.
