# TabSnap v0.3.0-alpha.1

Level 3 Edge alpha.

## Added

- Microsoft Edge runtime detection from `Edg/<version>`
- Edge snapshots recorded as `source.browser: edge`
- shared Chromium capture/restore implementation for Chrome and Edge
- Edge-specific package audit
- Edge compatibility browser test for capture metadata and portable-companion pairing
- separate `tabsnap-edge-v0.3.0-alpha.1.zip` release asset
- SHA-256 checksum for the Edge package
- Microsoft Edge installation and compatibility guide

## Unchanged privacy boundary

TabSnap still has no backend or account requirement.

The extension requests only `tabs` and `tabGroups`. Loopback companion access remains optional and is requested only after an explicit Connect action.

Passwords and decrypted browser state stay in the extension. The companion stores and transfers opaque encrypted `.tabsnap` bytes only.
