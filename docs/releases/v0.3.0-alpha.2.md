# TabSnap v0.3.0-alpha.2

Level 3 Firefox adapter alpha.

## Added

- Firefox Desktop 139+ runtime detection
- Firefox snapshots recorded as `source.browser: firefox`
- one shared WebExtension capture/restore engine for Chrome, Edge and Firefox
- Firefox-specific restore policy for privileged URLs
- native Firefox handling for `about:newtab`
- normalization of Firefox `docked` window state to the shared `normal` state
- production Firefox Manifest V3 package with stable Gecko ID
- Mozilla `web-ext lint` validation in CI
- deterministic Firefox release ZIP + SHA-256 checksum
- Firefox installation and compatibility documentation

## Unchanged privacy boundary

TabSnap still has no backend or account requirement.

The extension requests only `tabs` and `tabGroups`. Loopback companion access remains optional and is requested only after an explicit Connect action.

Passwords and decrypted browser state stay in the extension. The companion stores and transfers opaque encrypted `.tabsnap` bytes only.
