# Guide

TabSnap captures a browser workspace, encrypts it locally and gives the result back to you.

The first implementation targets Chrome.

## Planned flow

1. Capture the current browser workspace.
2. Review what was captured.
3. Enter a password.
4. Copy an encrypted string or save a `.tabsnap` file.
5. Move it however you want.
6. Import it on another machine.
7. Enter the password.
8. Review and restore.

Nothing needs a TabSnap server.
